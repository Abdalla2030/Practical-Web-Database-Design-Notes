# Practical Web Database Design — Study Notes

Chapter-by-chapter study notes for **Practical Web Database Design**, covering database concepts, relational design, SQL, implementation, security, and maintenance.

## About the Book

**Title:** Practical Web Database Design

**Authors:**
- Chris Auld
- Allan Kent
- Rudy Limeback
- Nigel Stanger
- Thearon Willis

The book introduces important database design steps and Structured Query Language (SQL), using a database- and platform-neutral approach.

## Repository Purpose

This repository provides organized summaries for reviewing each chapter without rereading the entire book.

Each chapter will have:
- A **README.md** explaining the main concepts, with examples and comparisons.
- A **presentation** for visual review, added separately.

These are personal study notes, not a reproduction of the book. Where necessary, the notes clarify simplified explanations or distinguish historical information from current practice.

1. Open the folder for the chapter you want to review.
